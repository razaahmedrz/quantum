Qiskit Programming

1. Introduction

Qiskit is an open-source software development kit for creating, simulating, and executing quantum circuits.

2. Basic Quantum Circuit

from qiskit import QuantumCircuit qc = QuantumCircuit(2, 2) qc.h(0) qc.cx(0, 1) qc.measure([0, 1], [0, 1]) qc.draw(output="mpl") plt.show()

3. Circuit Visualization

4. Explanation

The circuit starts with two qubits in the state |00⟩. A Hadamard (H) gate is first applied to qubit q0, placing it into a superposition of |0⟩ and |1⟩.

Next, a controlled-NOT (CNOT) gate is applied, where q0 acts as the control qubit and q1 acts as the target qubit. This operation creates an entangled Bell state between the two qubits.

5. Conclusion

This example demonstrates how Qiskit can be used to construct a simple quantum circuit, generate quantum entanglement using Hadamard and CNOT gates, measure the qubits, and visualize the resulting circuit.
