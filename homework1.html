Homework 1

Qiskit Programming

1. Introduction

Qiskit is an open-source software development kit for creating, simulating, and executing quantum circuits.

2. Basic Quantum Circuit

from qiskit import QuantumCircuit qc = QuantumCircuit(2, 2) qc.h(0) qc.cx(0, 1) qc.measure([0, 1], [0, 1]) print(qc)

3. Explanation

The Hadamard gate places the first qubit into superposition. The CNOT gate then creates a correlation between the two qubits. Finally, both qubits are measured in the computational basis.

4. Conclusion

This example demonstrates the basic Qiskit workflow for constructing and measuring a simple two-qubit quantum circuit.
